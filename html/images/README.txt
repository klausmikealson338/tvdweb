HOW TO ADD IMAGES TO YOUR TVD WEBSITE
======================================

CHARACTER IMAGES:
-----------------
1. Find pictures of the TVD characters online (Stefan, Damon, Elena, etc.)
2. Save them in the "characters" folder with these exact names:
   - elena.jpg (or .png)
   - stefan.jpg
   - damon.jpg
   - bonnie.jpg
   - caroline.jpg
   - klaus.jpg
   - katherine.jpg
   - jeremy.jpg
   - alaric.jpg

WEAPON IMAGES:
--------------
1. Find pictures of TVD weapons online (oak stake, daylight ring, etc.)
2. Save them in the "weapons" folder with these exact names:
   - oak_stake.jpg
   - white_oak_stake.jpg
   - daylight_ring.jpg
   - vervain.jpg
   - werewolf_bite.jpg
   - gilbert_device.jpg
   - boundary_spell.jpg
   - decapitation.jpg

WHERE TO FIND IMAGES:
---------------------
- Google Images: Search "The Vampire Diaries [character name]" or "[weapon name]"
- Pinterest: Lots of TVD fan images
- The Vampire Diaries Wiki (vampirediaries.fandom.com)
- IMDb: Official show photos

TIPS:
-----
- Use .jpg or .png format
- Make sure image names match exactly (case-sensitive)
- If images don't show, check that the file names match exactly
- The website will show placeholder text if images are missing

Once you add the images, refresh your browser to see them!
